# Adjacent-opposed cue development

This additional outcome-informed curriculum pairs each A cue with a distinct
one-bit-neighbor B cue of opposite valence. The eight A/B feature vectors are
full row rank, so one existing linear taste model can represent all labels;
the learner receives no phase label or hidden valence. This does not replace
the original random-codebook benchmark or constitute fresh qualification.
