# Fixed contact-cue filter developmental study

Compare two cue-shared learners on the eight existing development histories.
Both obtain the same explicit contact-cue comparison and pay the same declared
sensor work; `observe` ignores its result and `filter` suppresses taste credit
when contacted cues differ. Both use the same fixed motor freeze after A and
incremental spatial selector as the previous study. All observations, targets,
and learning remain own factual data; no valence labels enter the learner.

Capture complete A/B/C/D acquisition traces, anchors and frozen probes using
the prior cue-shared protocol. Measure each arm's acquisition survival, A/B
saved-current-reset retention, A/B interference and transfer against matched
reset, forced controls and genuinely cheap native-full. Include missing or
extinct histories as failures, not imputations. Each arm's physical probes
start from its own D bodies; comparisons across arms are whole-world outcomes,
not paired individual treatment effects. Freeze all rules before outcomes.

The filter is based on outcome-informed reused histories and assumes only
observable cue equality, not that equality guarantees identical valence. It
does not establish independent qualification, functional pressure or RSI.
Retain all prior evidence and do not open any closed reserve. Full readback and
work/storage/debt validation are required before drawing scientific conclusions.
