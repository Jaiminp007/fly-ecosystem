# Frozen cue-aware native-action proof

The all-context certificate spent substantial work proving bounds for cue
patterns that were not observed. This separate outcome-informed candidate uses
the body's actual already-computed contact/odor observation, not hidden task,
phase or valence. It runs only in opt-in frozen cue-shared probes, after the
normal sensor and taste/motor work and after the existing wall-only shortcut.
Training and default execution remain unchanged.
The cue-value proof is not used for forced-guarded controls, which may execute
midpoint even when the learned value prefers native; guarded probes retain the
wall-only shortcut instead.

For the selected observable cue, form the exact shared-plus-residual
coefficients for both steering actions. If all eight coefficients match
exactly, strict ties select native for any remaining features. Otherwise bound
the action-1 minus action-0 value: the first six steering features are known,
feature 6 lies in [0,1] and feature 7 in [-1,1], with an extra floating-point
margin. Certify native only if the upper bound is strictly below zero.
Invalid numeric inputs and inconclusive bounds fall back to the normal full
selector and guard. This does not infer whether midpoint is available.

On a certified non-wall decision, keep the already-paid observed points,
clear only the now-unused prior pair index and skip pair selection, guard and
steering-value evaluation. Advance steering RNG and last-decision state as the
frozen policy does; execute the same native command. Log uncomputed features,
recommendation and availability as null, and count unknown availability
separately rather than reporting a false observation. Charge proof operations,
all fixed retained proof-state bytes, and one declared operation per encoded
byte of cleared index plus the assignment. Preserve all past and terminal debt.
The byte and scalar charges are conventions, not machine-energy measurements.

First test cue routing, exact equality, conservative bounds, near ties,
non-wall fallbacks, RNG, saved/reset snapshots, dynamic storage and terminal
debt. Then compare the fixed combined wall+cue proof against the wall-only
policy on the same eight reused cue-shared D bodies and seeds, plus equal-access
reset and native and cheap native-full controls. Same-state equivalence does
not mean physical trajectories stay identical after prices change. A result is
development engineering only; no learned transfer, pressure, survival,
retention, fresh qualification or RSI criterion is relaxed.
