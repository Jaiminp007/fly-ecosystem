# PLASTICITY PROBE V1 (learning magnitude across links, read-only)

Date: 2026-11-02. Zero worlds. Reads frozen C4–C15 rows. Metric
pre-registered in-turn: per transferred row, RMS distance between
endpoint weights and transplanted (source) weights = how much the
link's 1792 ticks moved the weights. N=2 per cell — DESCRIPTIVE.

## Result: no plasticity collapse; weights keep moving everywhere

Link-2/link-1 RMS ratios scatter 0.69–1.26 across lines and arms,
both directions (C4 0.73–0.80, C6 1.02–1.09, C7 1.24–1.26, C13
1.00, C15 0.69–0.76). Absolute magnitudes stay ~0.7–1.3 RMS per
link on every line. No arm, line, or leg shows frozen weights.

## Reading

1. **LoP-as-frozen-weights is ruled out (descriptively).** The
   substrate keeps moving weights at full magnitude on every link.
   What fails is TRANSFER, not learning — confirms the
   acquisition≠transfer core fact from the weight side (V3
   showed it from the performance side).
2. **Adoption decline (V3) is not movement decline.** C14's loop
   adopts less across legs (31%→9%) while weight movement stays
   flat (sparse 0.78→0.88, static 0.78→0.90). The sandbox passes
   less, but learning moves as much — the loop's selectivity
   weakens, not the substrate's plasticity.
3. **Sparse doesn't reduce endpoint movement** (C14 sparse ≈
   static; C15 sparse ≈ static). Consistent-with (not proof of)
   compensation: the plastic half moves further. Hypothesis only —
   needs record-level logging to test (OPEN CELLS §4).
4. **Lossy forces re-learning** (C15 T1 1.1–1.3 > T2 0.76–0.97):
   scaled-down weights must re-grow. The lossy mechanism works BY
   compelling movement, not by preserving it.

True dynamical isometry (R350/Rosseau) stays unmeasured — needs
activations/records absent from stored rows (recorded, not claimed).
This probe tests the gross LoP signature only.
