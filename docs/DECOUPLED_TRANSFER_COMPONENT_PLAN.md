# Decoupled transfer steering diagnosis

On the eight reused candidate D worlds, run the original transfer probe seed
for 256 ticks with the same frozen D taste and A motor weights in every arm.
Independently copy A, B or D steering weights. Verify that A, B and D motor
weights match for all D survivors. Each arm pays the same 326 component writes
and receives the same sensing, physical starting world and inherited debt.

Report B minus A, D minus B and D minus A for budget-adjusted energy, net food
intake, and survivor counts, with per-history values and positive counts. The
comparison isolates model assignment within a shared initial world, but changed
trajectories can affect interactions and random draws. It is outcome-informed
developmental mechanism evidence, not qualification or a training signal.
Retain starts, endpoints, traces and hashed inputs/sources, independently
reconstruct assignments, costs and summary, and replay the captured runs.
