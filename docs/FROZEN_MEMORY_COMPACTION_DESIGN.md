# Paid frozen-policy memory compaction

Frozen probe inference never samples the motor, taste or steering training
reservoirs. Retaining these records still incurs byte-time charges. Test an
opt-in transformation only after the full probe model is frozen: clear those
reservoir arrays while preserving all model weights, RNG states, credit,
route state, pending/dead semantics and inherited debt. Never alter the
original acquisition checkpoint, compact an active learner, revive bodies or
use a future/fork label. This is an inference-only representation change, not
an autonomous improvement or an acquired skill.

Bill a conservative declared one-time operation per encoded byte in every
visited reservoir plus four assignments, including empty arrays; reset and
forced controls must receive the same optional operation and pay their own
actual costs. Invalidate cached storage size so the next tick pays the actual
smaller state. This byte-based schedule is an abstract proposal, not a measured
deallocation energy or proof of low-level operation completeness. All terminal
work and unpaid debt remain chargeable.

First verify identical frozen decisions on exactly equal factual observations,
route switches, RNG streams, both steering implementations, reset and terminal
paths, plus original-checkpoint preservation, exact restore and memory/work
billing. Then use the same eight previously reused D checkpoints to compare
incremental compacted current against uncompressed current, equally compacted
reset and forced-native, and cheap native-full. Same physical starts and
transfer seeds are mandatory. Apply the unchanged positive mean, 6/8 wins and
nonnegative aggregate survivor requirement against both reset and native-full.
The comparison is outcome-informed development evidence only; no retained
distinct skills, functional pressure, fresh qualification or RSI follows.
