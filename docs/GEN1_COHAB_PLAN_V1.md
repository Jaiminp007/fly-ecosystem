## Why (no weight copy: does sharing an interval with skilled agents teach naive agents?)
All heir/carry lines copy weights by hand. This line tests the
no-copy channel: naive agents forage WITH skilled agents (same world,
original cues, 1792 ticks, naive learning ON, skilled frozen) vs
naive agents foraging WITHOUT them — then both naive groups are
frozen and probed on original cues. No social sensors exist (ACT
void), so any effect is ecological/stigmergic (skilled agents shape
the shared food field; naive learn from the shaped field) or
competitive (skilled deplete; naive learn from scarcity). Either
direction is scored; no direction is presumed.
- Design per history (7 runs): train A512 (founders, learn on) →
  skillT/skillN frozen A-probes (256; gate) → shared world (12
  skilled frozen + 12 naive init learning, 1792, repro OFF) vs alone
  world (12 naive init learning + 12 frozen-init dummies, 1792 —
  bodies matched at 24, learners matched at 12; dummies forage
  poorly and die early, a conservative headwind disclosed) →
  extract the 12 learners per arm (own weights) → frozen A-probes
  (256, original cues, reference founders=12). Scored: probe cue-
  intake (not deaths).

  shared > 0 (cohabitation teaches). Else NOGO
  (`GEN1-COHAB-NOGO-V1`) — no teach (or competition dominates).
  No deaths scored; no copy/transfer/RSI claim.
