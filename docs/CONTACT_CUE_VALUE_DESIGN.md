# Prospective contact observation and direct action-value hypothesis

This is a human-proposed next hypothesis following the failed, closed
tick actor-critic bank. It is not a qualified learner, a correction to that bank,
an autonomous algorithm revision or authorization to tune on its outcomes.
No new performance bank or reserve is opened by this document.

## Evidence and boundary

The post-hoc policy diagnosis evaluates initialization and saved A/B/C/final
weights on the same first/last recorded own-observation contexts. On those
fixed contexts, learned policies changed only slightly and had very small
odor-to-acceptance contrasts. That observation alone does not identify the
cause of failed learning or justify choosing a larger rate.

Exact observer-instrumented candidate replay also reconstructs consumed patch
provenance. Many stationary intake mismatches occur because sensors discard
patches at amount <=.06 while intake still consumes them. This is a concrete
sensory/consumption boundary, not evidence that correcting it guarantees learned
behavior. The original sensor, simulator, failed outcomes and archives remain
immutable. Subsequent gates must still establish behavior on fresh histories.

## Prospective observation component

`learning/contact-cue.mjs` implements one opt-in component, currently imported
only by its tests. It returns the odor of the nearest patch within radius 15
from the body's actual pre-action position, regardless of amount. If none is
local, it returns the existing odor fallback. Ties keep the first patch in fixed
world order. The output is only four odor signs, never a patch ID, amount,
valence, action outcome, phase or another body's experience.

The component does not change food, regrowth, motor actions, survival costs,
physics, actual intake or reward. It is nevertheless a **new observation
intervention**, not a free repair to an old study. Empty local patch identities
remain observable by design; this is a disclosed artificial sensory assumption,
not a claim about real fly olfaction. Before performance, a wrapper must expose
only this local result and separately meter every actual query. The current
reference implementation scans patches at six scalar operations each, plus one
nearest comparison for each local patch. Its work must enter physical bills;
it is not zero-cost preprocessing. It retains no policy memory. Observer,
world-index construction and actual CPU/wall costs must also be reported.

The intervention still samples before movement. It does not make that cue a
guaranteed label for the later consumed patch. Current per-tick own energy
reward remains authoritative; neither a cue nor previous-food signal may be
silently treated as a supervised valence label. Multiple contacts must remain
possible in supported worlds even when absent from the prior performance grid.

## Substantive learner hypothesis, not an implemented winner

The next component to specify and engineer is a **direct expected-action-value
learner with bounded own-trajectory replay**, using the lawful raw sensors and
exact odor code, epsilon-greedy action selection and the same four motor actions.
This is a change of learning/selection mechanism from the small softmax
actor-critic, not a search over its rate or initialization. Action ranking should
depend on relative learned return estimates rather than require a small scalar
reward to produce a large softmax-logit displacement during one short lifetime.
That reasoning motivates a hypothesis; it does not establish advantage.

Use one fixed engineering configuration of tick-aligned Expected SARSA with
current-plus-permitted own history as explicitly decided before any new outcome,
live eligibility and bounded task-blind recent/reservoir replay. No hidden phase
or patch identity, codebook labels, cross-founder data, privileged fork target,
gradient injection or fitted observer result enters the learner. Specify its
actual finite feature map, update normalization, initialization, tie handling,
history size, replay release, terminal semantics and full byte-time/work model
before implementation is called complete. Do not choose among configurations
using this failed bank. Earlier SARSA failures remain failures; this candidate
would test a different action/observation/learning bundle on fresh data.

## Required causal controls and unchanged qualification

Use a prospectively locked two-by-two observation/mechanism comparison on fresh
histories: original versus contact observation, and unchanged tick actor-critic
versus the direct-value candidate. The original-observation actor-critic is a
matched explanatory control in that new design, not an unchanged rerun offered
another chance to qualify on a larger sample. Specify costs of active versus
masked sensory computations, and matched initialization/acquisition controls,
before outcomes. No contact information or unused circuit is charged to a
controller unless it is actually computed/retained as declared.

Retain frozen/reset/cue-blind/shuffled/null controls, the native reference and
same-interface fixed/random policies. An initial uniform tied action-value policy
is not acquired skill; separate A/B skill-over-reset and B/C acquisition must
demonstrate learning. All original founders, debts and terminal work stay in
denominators. Require nonnegative exact-count survival guards, separate >=95%
A/B advantage retention, original-ecology transfer over reset and both always-
accept modes, meaningful functional pressure and the same honest energy criteria.
Greater representational capacity, a replay overflow or parameter reuse alone
cannot satisfy pressure. Do not remove the pressure requirement if the new
architecture retains independent odor entries without substantive interference.

Before fresh seeds: integrate complete checkpoints and controls, independently
reconstruct the new update/sensory/cost/probe arithmetic, reject altered records,
then freeze every source, gate, multiplicity family, fresh exclusion input and
collection/replay/audit budget. A performance failure closes its reserve without
tuning, reselection or extension. Successful embodied qualification would still
leave at least two persistent autonomous revisions and copied-improvement
search-productivity comparisons unachieved. No RSI claim follows this design.
