## Why timing identifies the cause (opposite predictions, no new machinery)
- Gen1-placed GO'd but could not say toxin vs starvation (both deplete
  energy; deathCauses labels both 'energy'). TIMING breaks the tie:
  starvation cannot kill well-fed agents fast (fresh world, full food,
  naive gobbling from tick 0 — early fresh deaths cannot be hunger);
  toxins act acutely on exposure (fresh has the most). Depleted worlds
  starve slowly if at all (less food but also less toxin).
- Opposite pre-registered predictions: TOXIN predicts fresh-early
  mortality >> deep-early (acute, exposure-driven); STARVATION predicts
  the reverse-or-null (depleted dies, fresh never starves). The test
  discriminates cleanly where the labels cannot. deathCauses recorded
  descriptively (expect 'energy' both arms — context, not label, decides).
- Same placement verbatim (identical naive minds, frozen, 48 energy,
  V1 transplant + store-clear + freeze + book-rebaseline, reproduction
  off, same histories): the ONLY additions are (a) per-agent born/died
  table saved per row (fixes gen1-life's missing-table lesson), (b) an
  early-mortality scorer. No new engine contact (lineage read is
  gen1-cohort-proven; placement is placed-proven). No weight copy
  (init-to-self, zero learned bits).

## Design (2 histories × 2 arms = 4 mains; timing readout)
- Arms: deep (1024-deplete + place + 1792 live) vs fresh (place at 0 +
  1792 live). Same history per pair (layout matched). 1792-tick measure
  (full-horizon exposure, placed precedent).
- Metric: 200-tick... no — 256-tick early mortality (fraction dead with
  died ≤ 256; probe-length precedent for "acute") + full survival curves
  (median death tick) + deathCauses, all descriptive except the GO bar.
  Every placed agent observed full 1792 unless dead (no censoring —
  death IS the event; survivors censored at end but the bar uses early
  deaths only, all fully observed either way).
- Bank: fresh-18, 474307–474324 (2 histories × 9, 18 unique), minted
  post-fixtures, verified clean. No triage (frozen rationale: placement
  ops + lineage read both proven in prior runs; fixtures cover scorer +
  table logic). Caps: BT. Single attempt. Disk floor 1 GB (free ~2G;
  output ~1M — rows carry 24-entry tables; stop if <1G).
- Verdict (pooled n=2): GO (`GEN1-CAUSE-GO-V1`) iff pooled fresh-early
  mortality > pooled deep-early × 1.1 (acute deaths concentrate fresh —
  TOXIN measured as cause). Else NOGO (`GEN1-CAUSE-NOGO-V1`) — no acute
  fresh excess (starvation-or-null; direction reported). No void branch
  (mortality always scores; all-die/all-live both arms = NOGO with
  floor/ceiling noted). No transmission/transfer/RSI/population claim.
