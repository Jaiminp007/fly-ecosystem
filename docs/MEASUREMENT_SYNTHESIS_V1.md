6. **Bar, not luck** (CONFIG): sterile control = bar-65+legacy

Every audit resolves to EXOGENOUS structure: contacts set
residuals (1); bank luck + bar set births (2, 3, 6);
the window sets timing (4); depth never compounds (5).

generations (zeroed newborns); no transmission that changes

memory across banks (fresh draws)). The system has no
engine — all variance is imported (codebooks, patches,

audit said its piece); it is the shape of the pieces
together: a substrate that preserves structure perfectly
(residual <1e-7, bit-identical nulls) and generates none.
RSI needs an engine; the audits jointly report its
absence — which is why the program persists (functionally
