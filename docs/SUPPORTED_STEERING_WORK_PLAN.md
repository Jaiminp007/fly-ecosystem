# Supported steering declared-work audit

For every acquisition tape in the completed supported steering study, reconstruct
the recorded steering work from its initial checkpoint and factual decision and
terminal schedule, without importing the learner. Under the recorded abstract
accounting, a fresh acquisition decision costs 74 scalar operations, a pending
nonterminal update adds 1,199, and a terminal pending update adds 1,151. Verify
every reported decision work value, every final work counter, terminal work,
trace length and hash. Preserve the captured initialization and inherited work.

This is an independent counter reconciliation, not a proof that the declared
operation allowance covers every implementation instruction, that temporary
memory is fully priced, or that the abstract price reflects hardware energy.
It does not create new scientific evidence or qualify the learner.
