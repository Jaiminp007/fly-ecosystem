# Saved motor-value diagnostic

The outcome-informed fixed-speed intervention improves every available current
transfer fork, but the original transfer gate still fails. To locate the motor
preference without another parameter sweep, use only the seven existing factual
frozen-current transfer tapes and each acting founder's own A, B and C
acquisition checkpoints. The extinct eighth history remains missing.

For every recorded decision, reconstruct the existing 13 motor features and
score the three actions with that same founder's saved A, B and C weights.
Apply the implementation's exact full-speed-favoring tie rule. Verify that the
C greedy action equals the action actually logged in the frozen-current tape.
Record per-history choices, full-versus-stationary margins and the number of
choices that differ between saved snapshots on the same factual observations.
Verify all source, anchor and tape hashes. The comparison is descriptive of
preferences on the C-policy's visited states: A/B model choices are not actions
actually taken, and their hypothetical outcomes cannot be used as learner
labels or interpreted as causal results.

No new training, qualification seed, score threshold or motor parameter is
introduced. Evidence from this diagnostic may motivate a separately frozen
candidate and strong controls, but it cannot establish retention under pressure,
useful transfer or any autonomous revision.
