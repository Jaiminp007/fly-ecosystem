# Energy-balance and movement development

The full staged research goal is active again at the user's explicit request to
continue through project completion. Development remains reusable and exploratory;
neither passing software checks nor tuning can qualify a learner or establish RSI.

Attempt 08 replaces the previous-intake context split with the body's actual
signed budget-adjusted energy change on its own previous physical step. Its
before/after energy fields are charged as state; the subtraction is metered.
Common frozen inference clears this transient context equally in all versions.
Actual world costs, lifespans and original-founder denominators remain unchanged.
End-C anchors are now saved, enabling additional read-only diagnosis without
repeating training. Transfer includes both always-cruise and always-stationary
controls. Attempt 08 still fails transfer and B retention, so it is not promoted.

Two further hypotheses will be compared on the same eight development histories:

* Attempt 09 retains the half-speed cruise output and initializes the critic's
  context biases from its own first observed interval return divided by
  `1-discount`, clipped to [-8,0]. This gives a first estimate of ordinary energy
  costs before interpreting subsequent differences as advantages. It uses no
  world cost oracle, future rewards or phase label. All calculations, added
  configuration and readiness state are charged. The original zero initialization
  remains available. Reset clears the estimate; uniform inference compaction
  clears readiness, while preserving installed model weights.
* Attempt 10 uses the same initialization but permits cruise at output +1 rather
  than 0 (full rather than half physical maximum speed). The candidate, unlearned,
  frozen, reset and fixed-cruise controls all use the same output interface. This
  changes the experimental action interface, not speed traits or physical prices.
  It is not evidence that learning caused a benefit merely because movement is
  faster. Matched learning controls and transfer against the matching fixed cruise
  are required; legacy/default cruise remains output 0.

The functional-interference battery reinstalls factual A/B/current weights on
identical end-C bodies. It reuses overlapping probes, adds A:B and B:A plus an
exact A-copy sham, and reports the previously specified raw acquired-skill,
useful B acquisition, >5% transient A interference, net-food interference, 95%
A/B final retention and original-ecology transfer contrasts. No synthetic damage,
phase input or replay of probe rewards enters training. These are descriptive
development effects, not a fresh scientific qualification.

The independent Python core observer still covers only the original fixed
pairwise/shared-motor fixtures. The new mechanisms require a separate extension
before any independent reconstruction claim. Targeted own-signal, lifecycle,
checkpoint, physical-interface and intervention checks are used during development.

The completed attempts 09/10 still fail transfer. The next movement rule is an
explicit endogenous renewal heuristic: logistic prediction from the body's own
pre-action features learns a search target after a nonpositive own energy change
and a waiting target after a positive change. It updates after each physical
step, with no temporal-difference critic or hidden counterfactual label. This is
a human-designed adaptive-control hypothesis, not proof that waiting would have
been better on an observed cruising step. Its actual physical outcomes, controls
and costs must establish whether it helps. Frozen/reset inference uses the same
learner and interface; only acquired weights differ. Both half- and full-speed
cruise will be tried with the same fixed references.

The next development evaluation adds optional greedy movement only during
uniform inference compaction. Training and frozen-acquisition main arms retain
the same exploratory policy. In probes, all current/saved/reset models use
their own motor probability's .5 threshold; no model receives a special rule.
This is a new disclosed evaluation/deployment mode, not a retrospective change
to recorded results. It tests whether exploratory pauses explain part of the
gap to fixed always-cruise. Initialization, movement interface and actual costs
remain visible; no result is assumed to pass.

Greedy renewal inference still fails the joint gate. A separate navigation
hypothesis trains a classifier on the body's own executed cruise steps outside
local contact: target movement when its sensed food proximity increases, target
waiting/reorientation when it decreases or ties, and continue searching when no
food was sensed. Stationary/contact steps do not label a counterfactual cruise;
terminal eligible cruises are retained as failures. The next own sensor reading
completes the preceding one-step record. No patch identity, map, hidden valence,
future probe reward or synthesized trajectory enters this rule. Target switches
can make the proximity signal noisy; actual energy/retention/transfer outcomes
are still required. Contact contexts remain at the shared motor prior, while
search contexts learn from observed movement. The rate remains .1 initially.
