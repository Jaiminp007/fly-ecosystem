# Frozen gate-memory cost census

Both replay arms fail original-ecology transfer while frozen gate buffers remain
allocated. On each already recorded transfer-current probe, count actual own
decisions by body and calculate the gate reservoir's incremental encoded-byte
storage charge above an empty array. Also compute the one-time declared
operation charge of visiting the encoded reservoir and clearing its array, as
in the existing frozen-memory compaction convention. Use each probe's actual
pricing, starting memory and observed decision counts; include dead bodies until
their final decision. Verify trace hashes and preserve incurred versus paid debt.

The result estimates declared charge differences on recorded trajectories,
not a physical compaction intervention or guaranteed endpoint improvement:
energy, survival, RNG and interactions may change. Do not delete the historical
evidence, change training memory, assume frozen selection is inactive, relax
any gate, or claim independent physical simulation. This outcome-informed
descriptive check may motivate one matched, paid frozen-memory intervention.
