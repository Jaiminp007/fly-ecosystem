# Decoupled transfer stage diagnosis

Using the same eight reused candidate D worlds and original transfer probe
seeds, compare frozen B, C and D steering with D taste and identical A motor
banks. Verify A/B/C/D motor equality for every D survivor. Each arm incurs the
same 326 component writes, sensing, inherited debt and physical initial world.
Report C minus B, D minus C and D minus B energy, net intake and survival,
per history and in aggregate. Keep starts, traces, endpoints, source and input
hashes, and audit assignments, paid work, outcomes and exact replay.

This post-outcome diagnosis separates checkpoint effects in a common transfer
world, not their causes within an acquisition phase. It does not establish
fresh qualification, a learned preservation mechanism, or performance against
the reset and inexpensive native controls. No reserves are opened.
