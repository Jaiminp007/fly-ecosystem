# Direct-value continuing-world integration

`learning/value-cue-experiment.mjs` is a new opt-in offline wrapper. The engine,
platform, failed studies and frozen scientific sources are unchanged. There
is no new performance collector, seed bank or qualification result for this
wrapper. Its component arithmetic has an independent engineering checker;
the full continuing-world wrapper still needs its own independent audit.

change also includes representation, history, initialization and replay, so it
does not isolate one algebraic update or action-selection ingredient. Main
physical starts match except for the disclosed null assignments/native flags.
Native memory/neural acquisition is disabled in all matched non-native arms.

Contact cue selection runs before each choice and its actual six-per-patch plus
local-comparison operations enter the body work ledger and physical bill. The
blind/shuffled arms actually compute then mask it and pay that work. Original-
observation arms skip the contact query. Fixed/random policies do not compute

Observer scrambling and trace-copy CPU remain experiment costs to be included
in future complete runtime budgets. No hidden valence or patch identity enters
an own observation. The native source cue and selected cue are diagnostic fields
outside policy inputs; recorded events are cloned against observer mutation.

## Complete checkpoints and retained models

Joint checkpoints include physics, resource phase/RNG state, all original body
learners, exploration/retention/replay streams, previous own context, traces,
pending intervals, bounded factual buffers and incurred/paid/outstanding charges.
Original actor control's complete physics and learner continuation matches the
previous wrapper in the engineering comparison. This is a source-compatibility
check, not a new performance success or cross-runtime guarantee.

After A/B, observer-only archives retain each founder's weights; after C, the
candidate retains its full joint checkpoint. Neither archive reaches a learner.
Freeze clears pending/traces at the B boundary without changing weights or RNG;
acquired reset at B/C clears value/history/replay state but preserves lifetime
counters, streams, debt and bodies. The last surviving phase interval remains
pending as specified; no terminal label is invented.

## Fifteen paired skill, pressure and original-ecology probes

Probe versions are A:A/A:B/A:C/A:reset, B:A/B:B/B:C/B:reset,
C:B/C:C, and original-ecology transfer with A/C/reset/accept/acceptStationary.
The extra A:B version supports the earlier functional-pressure assay. A future
complete collector must also execute an exact A:A copy sham, reuse overlapping
comparisons and prospectively budget all worlds and audit work.

All probes start from the same candidate end-C physical checkpoint within each
family, use the same current private policy RNG and resource seed and disable
acquisition. No refill, revival, selected-survivor denominator or training
backflow is allowed. Only the model version's weight rows replace the current
weights. All original incurred debt, including dead founders' debt, remains.
Probe value is incremental energy minus the change in outstanding debt per
original founder, avoiding charging a historical cost twice.

**Inference-only compaction is explicit and uniform.** Before every value-model
probe, clear previous context, pending, eligibility and both factual buffers;
set acquired buffer counts to zero and freeze acquisition. These unused factual
records cannot influence frozen action values and are not retained as a
fictional active circuit. All model versions are compacted identically, with
no refund of historical memory/work costs. Weights, private streams, lifetime
work and existing debts are preserved. During a probe, frozen own context still
updates reactively at each decision; weights and acquisition remain frozen.
This is a new disclosed probe convention, not a rewrite of an old study.

Reset probe weights are zeroed by assignments. No random projection or fitted
initialization is run, so additional scalar initialization cost is exactly zero;
the unchanged streams are not reinitialized. All versions have the same compact
value-state shapes. Both honest energy accounting and the no-reset-cost-only
skill requirement remain mandatory. Fixed probes carry inherited debt but retain
no unused value circuit, and zero prospective contact-query work in transfer.

Transfer sets the original all-beneficial resource ecology, disables cue input
and contact queries, retains every lawful raw sensor/history input and requires
the future candidate to beat reset plus both same-interface always-accept modes.
A zero odor block alone cannot establish transfer. A missing/extinct end-C
source yields explicit zero new actions/value and cannot clear positive skills.
