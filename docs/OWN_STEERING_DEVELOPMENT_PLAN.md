# Own-steering development comparison

This is a proposed fixed development comparison on the eight previously reused
histories, not fresh qualification. Use the opt-in randomized acquisition
geometry for all matched arms; keep the original grid and every failed study.
Acquire A/B/C for 512 ticks per phase under learned, forced-native and
forced-guarded steering. All carry the same spatial interface, taste/motor and
steering machinery, actual-action credit, encoded state and operation charges.
Report each founder's available, native and midpoint decision counts, A/B/C
survival, endpoint energy and the hashes of its own saved A/B/C checkpoints.
If a population becomes extinct before a checkpoint, record it missing; never
substitute an earlier physical state or invent observations.

For retention, use the same end-C physical checkpoint for all forks. For A,
compare the frozen A-snapshot model against the frozen C-snapshot model and
reset; for B, compare frozen B against C and reset. Earlier weights must belong
to the same founder in the same recorded acquisition trajectory. Carry the C
physical state and RNG, original C debt and each probe's full setup work. The
current wrapper checks matching history, founder IDs, geometry and chronology;
the collector and independent audit must also prove actual snapshot ancestry,
because matching metadata alone does not prove it. Calculate retention only
when the saved-over-reset advantage is positive and the required support is
present; otherwise report it undefined, never a pass. The existing 95%
requirement and all survival/pressure conditions remain unchanged.

For original-ecology transfer, fork end C into frozen learned, matched reset,
matched forced-native and forced-guarded, plus the cheaper native-full control.
Use identical physical anchors and transfer seeds, no transfer learning, and
retain all incurred work and unpaid debt. The exploratory transfer gate is the
same as earlier development: positive mean budget-adjusted energy per original
founder, at least six of eight positive histories, and nonnegative aggregate
survivor difference against both reset and cheap native-full. Also report both
matched steering controls; a transfer-only pass is not a retention or
qualification success.

Before any new outcome collection, freeze source, inputs, action support,
comparisons and complete cost/provenance audit in a runnable protocol. The
existing functional-pressure intervention, fresh qualification, and at least
two persistent autonomous revisions with causal search-productivity controls
remain separate mandatory stages. The implementation now supports model-weight
forks, but the complete collector and independent frozen/reset audit are not yet
implemented and no new development result is claimed. A separate synthetic
seven-fork engineering audit is recorded in `OWN_STEERING_PROBE_AUDIT.md`; it
does not substitute for auditing the actual multi-history study.
