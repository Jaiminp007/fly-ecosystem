# Target-cue taste interface: fixed developmental intervention

Extend only opt-in odor-routed experiments with the cue of each already-sensed
spatial patch, in the same order as spatial points. This is an explicit richer
sensor: charge construction, retain and price all encoded cue bytes, and mask
every target cue in odor-free transfer rather than reading stale patch labels.
All model controls receive the same observation, per-target predictions and
metered computation. No patch valence, identity, map or future outcome enters
the policy. Existing default execution must remain unchanged.

For a viable recommended pair, score each cue with the body's actual learned
taste predictor. If both cue-derived expected signs sum to a negative value
(equivalently, acceptance probabilities sum below one), the fixed filter uses
native steering instead of an otherwise selected midpoint. This is a compiled,
outcome-informed combination of acquired taste predictions and steering, not
itself evidence of a newly acquired steering skill. Observe controls compute
the same scores but retain their original action. During acquisition, the
steering learner's pending action must be the action actually executed. Native
and forced-guarded controls remain forced, not filtered. Missing odor gives
both cues the existing all-beneficial transfer default and disables suppression.
Do not combine the new interface with wall or cue-proof shortcuts until their
interaction is independently implemented and audited.

First use a frozen physical headroom diagnostic on the eight existing filter
D worlds, comparing score-filtered versus scored-observe, equal-access reset,
and cheap native-full for A, B and original-ecology transfer. No new training,
refill, reserve or hidden label is allowed. Report energy and survivors, and
retain the original transfer consistency/survival requirements; frozen
interventions cannot establish acquisition, pressure or qualification. Only
after a correctly billed diagnostic may a fresh developmental learner be
specified. Preserve source, anchors, tapes, work, storage and debt; independently
check cue provenance, scoring, actual actions and physical replay.
