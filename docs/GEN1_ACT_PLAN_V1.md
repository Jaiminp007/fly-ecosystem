# GEN1-ACT PLAN V1 (FROZEN 2026-11-04 — zero-world audit, no bank, no runs)

## Why an audit, not an instrument (implementability bar first)
Give/DOSE imposed transfer driver-side (post-step energy surgery on
the agent's meals). The order now requires the act to be THE AGENT'S
OWN, conditioned on SENSED NEIGHBOR ENERGY. Before spending a bank or
a world, establish whether the substrate CAN host that (implementability
bar — all three must hold, evidenced from code, zero worlds):
(i) a sensor carrying another agent's energy (or a need proxy the
frozen policy already tracks); (ii) an actuator (or decision mapping)
by which the agent's policy outputs giving; (iii) a learning path or
frozen mapping that produces need-conditioned giving (frozen must
already map need→give, or learning must be reward-compatible with it).
- If all three hold → build the agent-side instrument (new plan).
  If ANY fails with no work-around inside license (no engine changes,
  no reward redesign, no reopened lines, frozen stays frozen unless
  the arm is learning) → INCOMPLETE-UNSUBSTRATABLE (void — the
  question is unaskable here; no bank minted, no seeds spent, no
  worlds run). Pre-registered: work-arounds that relocate the
  decision driver-side (signal-gating by fiat, contact-herding,
  mate-act repurposing) do NOT satisfy "own act from sensed neighbor
  energy" and are not scored as such.
- Executable premises (tests, zero worlds): import INPUTS/OUTPUTS
  from the engine; assert no neighbor-energy sensor exists; assert no
  give actuator exists; assert the reward is own-energy-only (by code
  reference — analytic). Fixtures green pre-audit.
