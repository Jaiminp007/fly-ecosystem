# Fixed cue-shared transfer component intervention

The post-outcome census identifies opposing saved shared/absent-residual value
margins on some factual transfer observations. It does not establish which
component helps or predict a new trajectory. Before collecting intervention
outcomes, run one fixed total-world diagnosis on all eight existing cue-shared
D checkpoints and their existing transfer seeds. Closed reserves stay closed.

Each arm starts with the same bodies, world, learned weights, inherited debt,
incremental selector and paid frozen-memory compaction. Apply exactly one of:

- Full: preserve both saved shared weights and absent residual weights.
- Shared-only: zero only the 16 saved absent-residual weights.
- Residual-only: zero only the 16 saved shared weights.
- Native: retain full weights but force native steering.

On every living body, all arms perform and pay the same additional 16 numeric
weight-write operations, including full/native sham writes; record and bill
the setup debt before any physical action. Other cue banks, motor, taste,
RNGs, bodies, resources and costs are unchanged. The cue is absent throughout
the original-ecology transfer fork. Capture full traces, starts, ends and
source/input hashes. No intervention outcome enters a learner.

Compare each masked arm with full and native using budget-adjusted energy per
original founder and exact survivor differences, per history and aggregate.
The component removals affect complete interacting worlds, including future
food, deaths, guard and RNG behavior; they are not fixed-neighbor or individual
causal effects. The result is exploratory selection on reused histories, not
fresh qualification, learned utility or a new policy gate. Require independent
checking of component assignments, setup bills, trace hashes, charged ledgers
and matched starting worlds. Preserve all prior failures and thresholds.
