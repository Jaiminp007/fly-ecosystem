# Supported learner pressure feature census

For each reused protect-arm D world, inspect both recorded A-probe trajectories
using the original saved A and saved B models. On every factual decision input,
independently compute both saved taste probabilities and both saved steering
predictions; advance the factual probe's own taste RNG to compare both taste
decisions with the same recorded draw. Verify the selected saved model's
probability, executed taste decision and steering predictions against the trace.
Count taste changes, steering changes where an alternative is available, their
overlap, and A/B probability differences; verify A/B motor weights match for D
survivors. Group by trajectory and history, record compressed input hashes and
trace hashes, and independently check aggregates.

These are model comparisons on recorded features, not physical interventions,
counterfactual rewards or evidence of causal contribution to pressure. The
trajectories differ between probes and are outcome-selected, reused development
data. Missing histories are not a pass; no reserve is opened or criterion altered.
