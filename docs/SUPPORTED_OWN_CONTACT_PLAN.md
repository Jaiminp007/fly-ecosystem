# Supported learner own-contact evaluation

Use only recorded factual stationary, accepted, odor-present homogeneous
contacts with a nonzero own `lastFood` sign in the protect arm's existing A and
B saved-A/saved-B probes. Pair each decision with the same body and tick's
observation. For each observed example, compute saved A and B cue-taste
probabilities and report Brier and log loss, signed-outcome counts, per history
and probe trajectory. Verify the actually selected saved model's recorded
probability and the stored trace hashes; independently recompute summaries.

This is a post-outcome, survivor- and action-selected observation census: no
outcome is inferred for rejected, moving, absent or neutral contacts. The
sampled probability has a 0.05--0.95 action floor and is not necessarily a
calibrated outcome probability. Loss differences do not establish an
intervention's physical benefit, functional pressure or fresh qualification.
No new rollout, external label or reserve is used.
