# GEN1-PLACED PLAN V1 (FROZEN 2026-11-04 — single authorized bounded run)

## Why placed (not born): the only clean world-contrast
- Gen1-cohort voided (no late births — mating economy stops) and gen1-life
  confounded duration with depth. Both failed on BIRTHS (timing/horizon).
  This line removes births entirely: place identical naive minds into a
  depleted vs a fresh world and score survival. No mating, no birth
  timing, no horizon mismatch (same K both arms), no weight copy (init
  restored, not transmitted), toxin-proof (survival).
- Construction (all precedented ops): parental run learns 1024 ticks
  (depletes — readapt-T1024 depletion level); snapshot init weights at
  tick 0; at 1024 copy init BACK over trained weights (V1 transplant
  op), clear store (memory-reset helper), freeze all (naive hold),
  set every fly energy to newborn-level 48 (uniform start); advance K.
  Fresh arm: same history, same placement at tick 0 (already init —
  copy is identity, still performed for symmetry + digest check),
  freeze, energy 48, advance K. End state both arms: IDENTICAL naive
  frozen minds at 48 energy — only the world differs (1024-depleted vs
  full). Depletion is isolated completely (positions carry over as part
  of the world — disclosed as the world bundle, same as return-novel).
- "No weight copy": no TRAINED weights move anywhere; the only copy is
  init-to-self-lineage (zero learned bits — same init the fresh arm
  already holds; digest-verified identical). Transmission 'none'
  throughout (no births at all — reproduction off).

- Histories: 2 (same history per pair for D and F — layout matched,
  depletion is the only difference). Arms: deep (1024-deplete + place +
  K) vs fresh (place at 0 + K). K=1792 (full-horizon starvation exposure;
