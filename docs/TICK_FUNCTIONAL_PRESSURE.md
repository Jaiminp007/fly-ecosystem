# Prospective functional interference intervention

## Scope and current status

The full staged research goal was explicitly set active again on 2026-10-25 at
the user's request. The intervention below is implemented and being validated
on named artificial engineering fixtures. There is no performance bank or
scientific pressure result. Failed studies, their confirmation reserves and
paused habitats remain unchanged.

`learning/tick-cue-pressure.mjs` adds a read-only snapshot crossover to the
existing tick learner. This tests a concrete question: do the actual parameter
changes accumulated by end-B impair an acquired A behavior while acquiring a
useful B behavior? It does not assume that shared parameters, odor orthogonality,
number of receipts or a changed network response establishes memory pressure.

## Intervention and matched controls

Use the candidate's end-C physical checkpoint for every version. In separate
frozen A probes, install saved end-A weights, saved end-B weights, end-C weights
or deterministic initial weights. B probes install saved end-A, saved end-B or
initial weights. Only the 161 policy/value weights are replaced. Current body
energy, genomes, age, positions, physical and policy random streams, counters,
original founder identities and inherited debt are identical within each family.
Pending outcomes and eligibility are cleared consistently and acquisition is off.
Resource seeds are unseen and shared within each family. There is no refill,
revival or reward backflow to training. All original founders remain denominators.

An additional exact copy/reinstall of end-A must produce the identical A trace
and result. This sham catches effects of copying, checkpoint installation or
accidental state mutation. It is a deterministic engineering identity check,
not an independent statistical sample or evidence that the intervention helps.

The existing 14-probe battery already contains six of these seven snapshot
comparisons. The only new scientific probe is A with end-B weights. The sham
adds one more execution. A future collector must reuse the overlapping results,
not run seven duplicate probes and hide that work from the budget.

Weights are the actual saved continuing models. Do not corrupt them, inject a
synthetic gradient, fit a privileged phase label or choose a weight subset after
outcomes. At a boundary the final nonterminal interval is still pending, as in
the core design. The A-to-B weight change includes that interval's eventual
completion; this is an intervention on the accumulated learned model, not an
isolated causal attribution to B-only rewards or a particular gradient component.

## Required raw effects before statistical inference

Let `V(F,M)` be incremental all-founder budget-adjusted energy in family F under
model M. For reset comparisons, use `R(F) = V(F,reset) + I(F)`, adding back its
disclosed initialization energy per founder. Honest charged values remain in
the evidence; this conservative skill comparison prevents reset construction
alone from establishing useful learning.

The implemented per-history effects are:

| Requirement | Effect that must have positive mean/bound |
| --- | --- |
| Acquired A skill | `V(A,A) - R(A)` |
| Acquired B skill | `V(B,B) - R(B)` |
| Useful later acquisition | `V(B,B) - V(B,A)` |
| Substantive transient interference | `V(A,A) - V(A,B) - .05*(V(A,A)-R(A))` |
| Physical functional change | A:A minus A:B net beneficial intake less toxin damage per original founder |
| Final A recovery/retention | `V(A,C) - .95*V(A,A) - .05*R(A)` |

The five-percent interference threshold is a new prospective design choice,
not an observed or tuned effect. It requires transient loss of more than five
percent of the earlier learned advantage. End-C must still retain at least
95 percent of that advantage; intermediate loss is not excused as final retention.
The separate B retention gate remains mandatory in the complete protocol.

The food contrast uses cumulative endpoint totals, whose identical starting
totals cancel. It rejects an interpretation based solely on differing new cost
ledger entries. It does not isolate all downstream effects of physically charged
computation on energy sensors, actions or survival. The intervention estimates
the complete budgeted model replacement under this simulator, not a biological
memory-capacity bound or an independent physics result.

All listed conditions are jointly required. A positive interference contrast
without positive acquired A skill and useful B acquisition is insufficient.
No final C recovery is inferred from the temporary-loss comparison. Equal or
absent extinct probes produce zero effects and cannot qualify positive skill.
The raw-effect function deliberately returns no `passed` or `qualified` field.

## Prospective study implications

Before any performance outcomes, include interference and food effects in the
same multiplicity family as acquisition, retention, sequence superiority,
original-ecology transfer and null equivalence. Preserve the existing standards:
separate A/B learned advantages and at least 95-percent retention, nonnegative
mean survival guards, and end-C transfer over reset and both always-accept modes.
Confirmation is opened only after all required development checks pass.

With 13 main arms, 14 original probes, A:B and the sham, the prospective budget
is **29 worlds per history**, with at most **27,392 collection world-steps**:
`13*1792 + 16*256`. Eight development and sixteen confirmation histories would
therefore mean 696 worlds and at most 657,408 collection world-steps, before
explicitly separated complete cold replay/audit work. These are draft budget
arithmetic, not a locked bank. Actual CPU/wall/storage and audit caps, source
closure, fresh seed exclusions, statistics, scorer and independent inference
checker still need to be frozen together. No seeds have been registered here.

Failure of the pressure requirement closes this candidate's joint qualification
claim, even if other effects look favorable. It must not trigger retrospective
threshold reduction, a new selection from these outcomes, opening an older
reserve or an unchanged sample extension. A pass would establish this bounded
interference assay, not general memory saturation or RSI. Persistent autonomous
algorithm revisions and copied-improvement/search-productivity comparisons
remain later obligations.

## Engineering verification

`scripts/tick-pressure-engineering.mjs` generates the complete previous named
world fixtures plus eight pressure/sham executions for each of four sources:
the long phase fixture, partial mortality, complete mortality and absent end-C.
Short mortality sources receive explicitly disclosed identical initial A/B
snapshots solely for lifecycle testing. They are not represented as learned.
The complete source import closure includes both independent Python checkers
and the underlying wrapper test dependencies.

`scripts/audit-tick-pressure.py` independently reconstructs model installation,
policy choices, ledger work, mortality/debt, paired full physical checkpoints,
sham identity and every raw contrast, using the existing independent Python
policy/ledger implementation. Captured-source Node replay separately binds
events to sensor/native/resource execution. Python does not independently
implement the physical simulator. Tests reject missing roles, foreign weights,
RNG/body/debt changes, hidden acquisition, source/hash edits, false sham and
altered reset/effect records. Statistical performance inference remains future
work and is not supplied by these artificial fixtures.
