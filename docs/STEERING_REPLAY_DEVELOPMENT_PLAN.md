# Fixed replay-steering developmental comparison

This prospective comparison uses only the eight already reused development
histories; it cannot establish fresh qualification. The fixed candidate uses
factual replay steering from initial acquisition. An otherwise matched original
steering arm is trained from the same initial worlds and seeds. Both use the
same routed taste and motor, randomized cue geometry and 512/512/512/256
A/B/C/odor-free curriculum. In both arms, freeze only the two motor banks after
A using the previously diagnosed intervention, while taste and steering keep
learning. This outcome-informed externally scheduled motor freeze is a
developmental control, not a learned phase detector or qualifying skill.

Preserve exact sources, protocol and hashes before collection; record full
decisions, physical receipts, observations, own-state anchors and final debt.
No bodies, resources, energy or debt are refreshed. Initial physical worlds
must match; changing steering necessarily changes subsequent trajectories and
total-world outcomes. The original arm is a comparator, not a substitute for
the required transfer controls. Missing checkpoints fail rather than being
imputed. Record actual per-founder action support and survival throughout.

At each arm's own D physical checkpoint, run frozen A and B probes with saved,
current and reset models, and original-ecology transfer probes with current,
matched reset, matched forced-native, matched forced-guarded and cheap
native-full. Every probe uses the same D bodies within that arm and the existing
separate phase probe seed. Saved/current probe setup and memory costs must be
matched; reset legitimately loses replay memory and may be cheaper. Pay all
work, retained memory and terminal debt; no counterfactual outcomes are used
as learning data.

For each required transfer control, require positive mean per-founder budget
energy, at least 6/8 positive histories and nonnegative aggregate survivor
difference. Report A and B retention only with all eight histories and a
positive saved-over-reset advantage; 95% is the unchanged descriptive
threshold. A passing development outcome is still not evidence of functional
pressure, fresh qualification, autonomous revision or search-productivity
improvement. Full trace readback must independently check model ancestry,
executed actions, replay updates, encoded storage and debt, and state its
physics and low-level operation limitations. No threshold or rate sweep.
