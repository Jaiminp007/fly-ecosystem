# Frozen steering target composition census

Read-only replay the AA and AB A/B probe arms from all eight existing
taste/steering crossovers. Capture the existing physical spatial-query results
without changing observations, learner inputs, world state, work or RNG. Verify
each original event hash, final checkpoint and endpoint exactly. For every
available pair recommendation, map its ordered point indices back to the
queried patch cues and evaluator-only codebook valences; verify point geometry.
Classify both-beneficial, mixed and both-harmful pairs by executed steering
action. Compare the saved A taste predictor's own acceptance propensities for
the two selected cues as an offline diagnostic, not a new sensor or label.

This is a post-outcome observational census on selected D survivors and reused
worlds. Cues and valence are never supplied to the learner. No physical effect,
counterfactual action value, new ability, fresh qualification or causal claim
follows from category frequencies. Preserve source and input hashes and do not
open reserves. A subsequent learner would require explicit lawful target-cue
observation, complete work and storage billing, matched controls and new
physical development testing.
