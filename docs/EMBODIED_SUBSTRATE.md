# Continuing embodied learner: preparation

Implemented after [Astra's review](ASTRA_REVIEW_DECISION.md), alongside the frozen [intervention diagnostic](INTERVENTION_STUDY.md). This module set is preparation for a separate prospective study. No embodied benefit, retention gate, autonomous algorithm revision or RSI result is claimed.

- `learning/continual-regimes.mjs` changes resources in the same living bodies across stable A, moving B, scarce C and a return to the stable family. Each phase uses its own resource seed. Transitions preserve food amounts, total energy, bodies, all acquired state and the simulator RNG streams. They do not replay A's early world in B or refill agents. Moving B shifts renewal centers on an explicit experiment clock.
- `learning/embodied-control.mjs` uses an opt-in `World.step` experiment hook to choose a speed from the body's current permitted observation. No preview simulation or counterfactual label is available. The existing steering/other-motor scaffold remains disclosed. A declared extra energy charge enters physical dissipation and reward; functions are never stored in world checkpoints. The live platform does not import the adapter.
- `learning/own-experience-learner.mjs` creates a separate empty learner per founder, with a default 64-record limit. It learns observed own-trajectory energy change after an eight- or 256-tick window. Overlapping windows wait for their true endpoints. Death completes partial windows using zero usable terminal energy. Models reject another body's input and stored experience. Conditional-outcome and direct-IPW formulations are experimental options, not adopted policies.
- Frozen acquisition and acquired-state reset are separate interventions. JSON continuation preserves the world and learner state together. Pending outcomes and three-decision working history are bounded separately from the fitted record store; future accounting must price both and the optimizer matrices.

The A/B/C sequence uses three 512-tick phases and a 256-tick return, totaling 1,792 ticks within the original founder lifetime range. Tests exercise memory eviction, own-label provenance, deaths, exact continuation, conservation at resource transitions and opt-in price accounting. An engineering seed reproduces complete ordinary-world state against the captured pre-hook engine in both existing environments through tick 1,456. These are software/compatibility checks, not independent learning-performance evidence.

Before qualification: select a justified candidate from the intervention diagnosis, lock fresh task/resource seeds and practical per-skill/survival noninferiority margins, specify costs for storage, inference, updates and migration, and account for whole-life worlds plus all read-only probe branches. Every founder stays in the denominator. Add the original incumbent, a matched-budget incumbent, frozen-after-A and acquired-reset controls, and strong fixed/reactive policies. Retention probes must use unseen examples after interference, with a matched earlier-model reference in the same end-sequence bodies. New-regime learning, each retained skill and survival must be reported separately.

No qualification campaign has started. A passing diagnostic cannot supply an embodied qualification result, and passing implementation tests cannot supply either result.
