# Odor-routed fixed development comparison

Use the eight previously reused development histories, never the closed reserves.
All acquisition arms run the same randomized cue geometry and the fixed
512/512/512/256 A/B/C/odor-free curriculum. The fifth, independent original-
ecology transfer probe uses `probeSeeds.transfer`. No bodies are replaced and no
energy, food or unpaid debt is reset at phase boundaries.

Compare learned steering with matched forced-native and forced-guarded steering;
also compare learned steering frozen after A and learned steering with both
motor banks, taste and steering reset at each later phase. Each arm carries and
pays for the same routed architecture and observes its own executed actions.
Freeze and reset setup operations are billed. Record each founder's present and
absent decisions by actual speed and steering choice, A/B/C/D snapshots and
survival. A missing checkpoint due to early extinction stays missing.

Use the candidate's D physical checkpoint for all frozen probes. For each of
A and B compare that founder's saved model, D model and reset model in the same
task and physical world. Report 95% retention only when the saved-over-reset
advantage is positive and all required histories and support exist. Transfer
compares frozen current against matched reset, native and guarded plus cheap
native-full, all from the same D physical state and independent transfer seed.
The unchanged exploratory gate requires positive mean energy, at least six of
eight positive histories and nonnegative total survivor difference against both
reset and cheap native-full. Missing histories fail, never count as zero or wins.

Freeze exact sources, inputs, controls, trace schema and audit code before
collection. Save complete decisions, physical receipts, observations, anchors,
final checkpoints and source hashes. Independently check model ancestry, action
support, frozen weights and charged work/storage/debt; disclose any remaining
physics or low-level operation limitations. This reusable development comparison
is not fresh qualification. The unchanged full objective still requires
distinct-skill retention under functional pressure, fresh audited qualification
and the later autonomous revision and causal search-productivity stages.
