# Filtered guarded focal-policy diagnosis

Select every founder whose survival differs between the paid filtered guard and
its matched native control, using the already observed development outcomes.
For each selected founder run two interventions from the same anchor and transfer
seed: all others guarded with the focal native, and all others native with the
focal guarded. Every body continues to compute and pay for the filtered selector,
guard and scratch state; only the focal numeric mode changes. Preserve initial
debt and terminal work. Save source and input hashes, decisions, receipts, final
checkpoints and the focal and whole-world outcomes.

This outcome-selected diagnosis is not an independent test, qualification or a
training dataset. The interacting world can change RNG consumption and future
food competition when a focal policy changes, so the intervention estimates a
total effect within each background, not an isolated fixed-neighbor effect.
Counterfactual outcomes must not be fed to any future learner. Use the results
to identify which information an own-experience learner may need; do not tune
the guard against these outcomes or weaken the original headroom gate.
