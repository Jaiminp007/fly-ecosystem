# Learned contact-action gate

The compiled stopping witness increased own examples but is not an acquired
skill. Test a phase-blind two-action contextual bandit that chooses whether to
keep an already proposed moving action or stop only when the body has accepted
an odor-present homogeneous contact. Its inputs are the body's current cue,
energy and taste acceptance probability; neither stage identity, external
valence nor counterfactual feedback is available. A fixed epsilon-greedy
selection learns only from that body's actual budget-adjusted one-step energy
change. Current taste and steering learning remain as before; the gate records
the actual executed action and never fabricates a stopped outcome.

Compare the learned gate with an architecture-matched random-action gate. Both
compute both values, draw the same number of random values, store identical
state shapes and train on factual outcomes; the random control uses the same
draw to select an action uniformly. Also retain matched selector-shadow, reset
and cheap native controls. Count and pay all selector, update, initialization,
storage and terminal work, including outstanding debt. Both gate actions must
be actually sampled; frozen probes must preserve trained gate models and their
saved-A versus saved-B alternatives. No phase-dependent stopping override is
used. Any exploratory development run uses the original eight reused histories
and the original pressure, retention and transfer comparisons; a pass is not
fresh qualification. Preserve prior failed controls and closed reserves.

First validate factual action provenance, no foreign labels, equal reported
work and storage, two-action exposure, freeze/reset behavior, restore and debt.
Then predeclare the exact full physical schedule and eligibility/readiness
criteria before collecting outcomes. A positive short-horizon estimate alone
does not demonstrate an acquired skill, functional pressure or autonomous
revision; stop if implementation cannot preserve the required controls.
