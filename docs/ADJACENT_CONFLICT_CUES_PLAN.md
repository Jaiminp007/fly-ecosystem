# Adjacent-opposed cue pressure development

The observed B updates generally improve A rather than causing functional
interference; simply extending B causes extinction. Define a fixed additional
curriculum that makes actual learned generalization more likely to face
conflicting evidence without corrupting weights or providing a phase label.
Retain each seed's original four A cues and valences. Give B four distinct
one-bit-neighbor cues, each paired with the opposite valence. Select a
deterministic one-to-one matching whose eight cue feature vectors have full row
rank in the existing 11-feature taste model; retain four other distinct C cues
with balanced valences. The generator belongs to the environment, not the
learner, and the organism receives only its existing cue observations and own
physical outcomes. No map, true valence or family identifier enters control.

The full-rank requirement verifies that one fixed linear taste model can
represent all eight A/B labels simultaneously; it does not imply the organism
will learn them or that food proximity makes the tasks physically attainable.
Test codebook determinism, uniqueness, opposite pairing, balance, rank,
baseline-A physical neutrality and checkpoint restoration before performance.

Then run the original 512/512/512/256 schedule and original eight development
histories with observe/target-filter arms and unchanged paid sensors, A freeze,
probes, pressure, retention, survival and transfer comparisons. Capture and
audit all costs, own credit, model ancestry and tapes. This explicitly
additional, outcome-informed curriculum is not the original random-codebook
benchmark and cannot replace it or count as fresh qualification. No existing
threshold is weakened, no reserve is opened, and no post-outcome selection or
synthetic gradient may enter training.
