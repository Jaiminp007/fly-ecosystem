# Supported B-phase taste replay audit

Independently reconstruct factual taste learning and reservoir selection during
the recorded protect-arm B acquisition phase, using each initial checkpoint and
its own executed-contact outcomes. Classify current and replayed sample cues by
the offline codebook's disjoint A/B memberships, verify model states, sensor
outputs, encoded storage, trace hashes and exact captured-source continuation.
Count samples across all bodies active in B, not just D survivors.

The codebook categorization is auditor-only; the learner receives only its own
cue and factual outcome. This can test whether replay revisits A during B, but
cannot prove its effect on physical pressure. It uses no new rollout for outcome
selection, no hidden labels as learner inputs, and no qualification reserve.
