# Vision milestone 1 verdict: MET (with the V1a refinement)

Frozen Track A audit, zero new worlds — assembled entirely from ledgered
evidence. Milestone: "repeatable benefit from lifetime learning on held-out
tasks, including a loss of benefit under memory reset."

## Repeatable benefit: DEMONSTRATED (fresh banks, repeatedly)

- v2 fresh qualification PASS on 8 prospective histories
  (`docs/TASTE_FRESH_QUALIFICATION_V2_RESULTS.md`): +5.08 vs unlearned (8/8),
  +3.30 vs frozen-after-A (8/8), skill existence (aSkill +1.33, bSkill +1.39),
  retention (A ≥95%, B true), transfer noninferiority. First fresh PASS.
- R=4-alone 14-bank series: lifetime superiority +3.99 to +5.69 on EVERY
  fresh bank (`docs/RSI_TASTE_NEGATIVE_SYNTHESIS_V2.md:33`). No bank luck.
- Development-stage gains vs frozen/reset reproduce across dev banks
  (M-GATE/S-GATE/M-RELEARN control arms, fresh seeds each).

## Loss under memory reset: DEMONSTRATED (frozen), REFINED (reset)

- Stopped learning loses the benefit: frozen trails candidate by +3.30
  (8/8, fresh qual). The loss is real and repeatable.
- Wiped memory recovers it: reset noninferior (+0.88, 6/8 within margin;
  v1 strict superiority also passes), and V1a proves relearning completes
  within 0 ticks of the wipe (`docs/M_RELEARN_RESULTS_V1A.md`). Wiping is
  cheap because relearning is instant — not because learning is worthless.

## The V1a caveat (preserved, not hidden)

Trained ≡ zeroed per-tick behaviorally (M-RELEARN V1a, S-GATE probes at
0.0-transfer). The lifetime benefit lives in aggregates (survivors, totals,
skills), not per-tick behavior. Mechanism puzzle for the record — but the
milestone counts the benefit, which is measured, fresh-banked, and repeated.

## Verdict: MET

Both clauses hold on held-out banks with pre-registered gates. v1-fresh
FAIL-source stands as the bank-luck control that makes the v2 PASS
meaningful, not as a contradiction (different seeds, same bars).
