# Factual B-update source decomposition

Reconstruct the own B acquisition examples and rbase reservoir draws from the
recorded shadow and stop event tapes and B-start taste models. Reproduce the
two sequential updates, all four random draws, reservoir/recent state and
clamping, and compare each resulting model to its B-final checkpoint. Separate
actual current-example updates, actual replay of A-tick records and actual
replay of B-tick records. Classify by each factual sample's original tick only
for offline analysis; do not expose stage labels or hidden valence to a learner.

For each source sum actual incremental shared-logit changes evaluated on the
four A cue vectors and actual incremental A-cue residual changes, across the
same bodies, alongside update counts. Verify that source sums reconstruct the
saved A-to-B component differences and do not treat additive attribution as a
counterfactual: later gradients depend on earlier actual updates. Count all B
entrants, including bodies that die, and separately report D-survivor results.
Verify tape hashes, own decision-observation pairing, final taste states and
source hashes. These are outcome-informed factual descriptions, not physical
interventions, qualification, or proof of independent dynamics or pricing.
