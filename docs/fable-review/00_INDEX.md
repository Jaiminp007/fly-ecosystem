# Review package: fly-ecosystem / RSI (prepared 2026-11-13)

This folder is a briefing for an independent reviewer. Read it in order:

1. [01_PROJECT_AND_VISION.md](01_PROJECT_AND_VISION.md): what the project
   is, the milestone status, and how the RSI claim has changed over time.
2. [02_RSI_EARLY_LINES.md](02_RSI_EARLY_LINES.md): every RSI line before
   2026-11-11. All of them failed or were closed.
3. [03_RSI_V1_TO_V4.md](03_RSI_V1_TO_V4.md): the taste-program search line,
   up to V4's narrow pass.
4. [04_RSI_V5_TO_V7.md](04_RSI_V5_TO_V7.md): the stronger three-criterion
   test (C1 update-rule revision, C2 invention, C3 transfer). Full numbers.
5. [05_METHODS_AND_CODE.md](05_METHODS_AND_CODE.md): code map, seed banks
   and statistics.
6. [06_DATA_INVENTORY.md](06_DATA_INVENTORY.md): where every run's raw data
   lives.
7. [07_AUDIT_FLAGS_AND_OPEN_QUESTIONS.md](07_AUDIT_FLAGS_AND_OPEN_QUESTIONS.md):
   known weaknesses and open questions.

These summaries were written by the agent that ran the experiments, so they
may be biased. The primary sources are the docs, the scripts and the
evidence files they cite, and the reviewer should check claims against them.
