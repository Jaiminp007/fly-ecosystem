# Delayed-cue memory task

Protocol and seed-level results generated by scripts/memory-task-evaluation.mjs.

- Held-out accuracy: learned 66.3%, frozen 56.3%, reset 56.3%.
- Paired learned minus frozen difference: 10.0 percentage points (95% t interval -12.6 to 32.6).
- Ten independent seeds; 64 training and 48 held-out trials per seed and arm.
- This compact, engineered task tests whether this controller implementation retains a delayed cue. It is not evidence of general intelligence, biological memory, or performance on the open-ended ecosystem task.

See results.json for the fixed protocol, each seed, source hashes, and timing.
